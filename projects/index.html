Projects

Things I've built, each with the lesson it taught me. Not a skills grid — the code is on GitHub if you want to check my work.

Current

wyla — a semantic layer agents can use

A provenance-typed knowledge graph fusing five data sources, served to AI agents over MCP and Google's ADK, with a guardrailed analyst agent running in a Python sandbox. My open-source laboratory for the ideas I work on at Amex. Lesson: design the agent's tool surface around questions, not tables.

ui-for-ai — components for agent interfaces

Nineteen drop-in animated React components for streaming, thinking, and agent workflows — shadcn-compatible, Tailwind v4, Framer Motion. Born from rebuilding the same "agent is thinking…" UI for the third time. Lesson: AI apps have a small, repeating grammar of UI states; codify it once.

ClaudeWatch — mission control for coding agents

A macOS app to monitor and dispatch multiple Claude Code sessions in parallel. Lesson: once you can see all your agents, you delegate like a manager instead of babysitting like an operator.

liteagent — agents in 3 lines instead of 30

A deliberately minimal agent library, written to find out how much of the framework ceremony is load-bearing. Lesson: less than you'd think — a loop, a tool registry, and a stop condition carry most of the weight.

Personal

hukam — the day's Hukamnama

Fetches the daily Hukamnama. A small tool for a daily practice — the kind of software that only needs one user to be worth writing.

moneymanagement & portfoliorebalancer

A Bloomberg-style personal finance dashboard and a rebalancing tool — where the bets get operationalized. Lesson: building your own money tools forces you to define what you actually believe about risk.

Earlier

Google Search & Books (2021–2024)

Metadata clustering that cut ingestion time 86%; a partner-selection model for Google Books saving ~$800K/year; a copyright-monitoring service that reduced non-compliance 30%. Details in about.

Pill Mill Detector (2018)

An ML detector for opioid over-prescription patterns, built at the Code4PA hackathon — won "Most Optimized Solution." My first taste of data work with real-world stakes, and probably the reason I still gravitate to it.
